Prompts

Every prompt is a Markdown file. Edit one below and it is stored under data/prompts/; delete that file — or use “Use the default” — to go back to the built-in one. The JSON schema of each answer is added by the code, so a prompt stays free of braces and placeholders.

Some prompts name roles and fields the code checks the answer against (source_ids, role names, exact citations). Removing one can drop generated content without an error — keep those names as they are.
